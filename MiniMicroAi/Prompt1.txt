== PERFORMANCE AND SECURITY ==
- Settings aur frequently used data cache mein, DB reads/writes batch aur minimal.
- Rate limiting, Telegram initData signature verification, input validation, admin-only route guards, audit logs, secrets sirf env/secrets mein.
- Security problems list ke har point ko cover karo: https://github.com/mr-daaku/hosting/blob/main/MiniMicroAi/Security-problems.txt
- Race conditions, replay, duplicate tx, multi-withdrawal ke liye locks/transactions.

== WORKFLOW (is order mein) ==
1. Requirements samjho
2. Problems aur unke solutions list karo
3. System design: low DB load, fake deposit reject, multi-withdrawal block, caching, settings cache
4. Roadmap
5. File structure
6. Steps mein divide karo
7. Poora code likho
8. Verify karo
9. Test karo
10. Error mile to fix karo

== WALLET AND DEPOSIT ==
- User data save karo: userid, username, name, wallet_index, created_at, referrer, balances, etc. Wallet ka full address database mein SAVE NAHI hoga; address MNEMONIC secret (12/24 words) + wallet_index se har baar generate hoga.
- wallet_index sequential atomic counter (1, 2, 3...), duplicate na ho.
- Chains: BNB, ETH, TRON, SOL, BTC, TON. Jahan stablecoin support ho (BNB/ETH par USDT, USDC, etc.) wo add karo.
- Coins: USDC, USDT, BNB, GRAM (TON native), BTC, TRX, SOL.
- Deposit scan Alchemy API se (secret ALCHEMY_API). Scanner ko test karo.
- Fake deposit reject: confirmations check, tx hash unique (duplicate credit block), correct token contract verify, amount/decimals verify, memo/address match.
- Reference system: ominiaibot-main.zip (https://github.com/mr-daaku/hosting/blob/main/MiniMicroAi/ominiaibot-main.zip) ka deposit/withdrawal logic dekho aur seekho.
